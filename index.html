EntityManager has interface

EM decorator implementation

Single EM for each requests

                
final class EntityManager extends EntityManagerDecorator
{
    protected ArrayObject $fallbackContext;
    protected $wrapped {
        get {
            $context = $this->getContext();
            if (! isset($context[self::class])) {
                $context[self::class] = ($this->emCreatorFn)();
            }
            return $context[self::class];
        }
    }
    public function __construct(private Closure $emCreatorFn)
    {
        $this->fallbackContext = new ArrayObject();
    }
    private function getContext() : Co\Context|ArrayObject
    {
        return Co::getContext((int) Co::getCid()) ?? $this->fallbackContext;
    }
}

Pooling mode:

  • per request
  • per transaction
  • per statement

Pooling mode: per request 


        $connection = $entityManager->getConnection();
        $connection->query('SELECT sleep(1)'); // connection established
        // Now in DB pool N-1 available connections
        sleep(1);
        $connection->query('SELECT sleep(1)'); // reuse connection again
        sleep(1);
        // After 4sec processing this request, connection will be released

Pooling mode: per statement 


        $connection = $entityManager->getConnection();
        $connection->query('SELECT sleep(1)'); // connection established
        // PHP keep fake connect
        sleep(1);
        $connection->query('SELECT sleep(1)'); // get new connection again
        sleep(1);
        // After 4sec processing this request
        // real DB connection used 2 times (total 2sec)
